# Frontend - Campus Question Bank

Static pages:
- `index.html`
- `upload.html`
- `materials.html`
- `contact.html`

JS calls backend APIs:
- `/api/upload`
- `/api/materials`
- `/api/materials/:id` (not currently used by UI)
- `/api/contact`

Set `window.SUPABASE_URL` and `window.SUPABASE_PDF_BUCKET` in your hosting environment.
